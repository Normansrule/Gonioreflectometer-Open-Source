# opengantry

Host software for OpenGantry Lite. Install on the Pi with `pip install -e ".[pi]"`, on a PC with
`pip install -e ".[dev]"`. Subpackages: `gantry` (axes, kinematics, collision, Moonraker, power,
encoders), `camera`, `calib`, `hdr`, `plans`, `brdf`, `scan`, `svbrdf`, `export`.
Machine description: `config/machine.yaml`. See the repository README for the project.
