# Toward OSHWA open-source hardware certification

Certification is free and self-declared at [certification.oshwa.org](https://certification.oshwa.org/).
It needs the design to meet the Open Source Hardware Definition and the documentation to be public.

## Checklist (milestone M6 in the roadmap)

- [ ] Repository made **public** (it starts private while the design settles).
- [ ] Onshape document set to **public** and linked from the README.
- [ ] Hardware licence CERN-OHL-S-2.0, software GPL-3.0-or-later, docs CC BY-SA 4.0 — present in `LICENSES/`.
- [ ] Original design files published: Onshape link + STEP exports for every custom part.
- [ ] Editable formats: STEP + 3MF + native Onshape; BOM as CSV.
- [ ] Assembly instructions for every module (8-section READMEs).
- [ ] No vendor CAD redistributed (links only).
- [ ] Project name and logo do not use anyone else's trademark (no "Stanford", "Raspberry Pi" or "Klipper" in the product name).
- [ ] Apply: choose a project UID, list the hardware, software and documentation licences, link the repo.
- [ ] Add the certification mark and UID to the README and to an engraved spot on the base.
