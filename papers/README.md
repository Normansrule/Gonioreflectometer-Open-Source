# Papers

Gonioreflectometer PDFs to work from. Get them with:

```bash
bash scripts/get_papers.sh
```

| Folder | What | In git |
|---|---|---|
| `open/` | open licence or US-government public domain (R1, G1, G6, G21, G22, G24, G25, G37, G38, G48, G49) | yes |
| `personal/` | author or vendor copies: R2 (CS348b slides), R11, R14, R17, R39, G9, G11, G16, G41, G42, S13 | no: the repo goes public in stage 16 |

List and licences: [papers.tsv](papers.tsv). Paywalled papers (DOI only): [REFERENCES.md](../REFERENCES.md), section G.
