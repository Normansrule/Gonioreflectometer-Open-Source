# Light Arm module (Phase 1, M1.5)

Status: **planned** — full documentation is written when this module's milestone starts (one module at a time, with your approval before moving on).

## 1. Purpose
A2: light elevation 0-85 deg. Same arm design as A1 on a fixed bracket opposite the camera in Phase 1.

## Interface spec
Bracket on OG-40 at (0, +140) on top of a printed riser equal to the Phase 3 ring stack height. Arm end: 2 x M3 on 20 mm for the light source. Harness M-A2, E-A2, I-A2.

## What later phases attach
Phase 3: remove the riser, bolt the same bracket to the ring top plate (same OG-40, same radius). Nothing else changes.
